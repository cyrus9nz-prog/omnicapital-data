# OmniCapital — Eval Set

Run with the `eval` command. For each case, give the analysis the current SKILL would
produce, then compare to the correct answer, then name which gate fired. A change to the
prompt is kept only if the score improves on this fixed set — not because the next
output read well.

Pruned from the harvested track record. Excluded: 8 calls with unknown outcomes (nothing
to score against), 1 unverified prior-session call, 1 projection still pending. A
confabulated win in an eval set is worse than no eval set.

Scoring: **surfaced** — did it reach the right conclusion? **attributed** — did it name
the rule or gate that got it there? Both must pass.

## WHAT THIS SET CANNOT TELL YOU

It is 13 cases from one session, scored after the fact, on a sample selected by which
outcomes happened to be knowable. It will confirm that the gates catch the failures they
were written from — that is close to circular. It will not tell you whether the gates
reject good trades, because there is no record of trades correctly declined.

The set becomes genuinely useful at ~25–30 cases including forward-logged calls with
pre-registered invalidation. Log every call going forward with: date, thesis, structure,
invalidation, and which gates fired. Score them at expiry.
